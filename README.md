## 🦭 如果你只是想試試看

如果你平常有在跑《黑色沙漠》的大洋大航海與物資交換，可以直接下載最新玩家版試試。

**第一次使用，你只需要記住這 3 步：**

### ① 先準備遊戲交換截圖 📷

在遊戲中把一輪物資交換資訊截圖保存下來。

建議遊戲畫質設定在 **「中」以上**，並將遊戲介面調大一些，會比較有利於 OCR 辨識。

### ② 開啟航海助手 → 匯入截圖

程式裡找到：

**「OCR／截圖辨識」 → 「匯入截圖」**

把剛才的交換截圖選進去即可。

> 💡 不需要自己裁圖、不需要修改圖片，也不需要懂 OCR。
>
> > 正常情況下，直接把遊戲截圖丟進去就可以開始。

### ③ 看 OCR 結果

辨識完成後，程式會進入 **OCR 人工確認頁**。

看到：

* ✅ 正確 → 直接放行
* ✏️ 有錯 → 手動修改
* ❓ 不確定 → 看原圖再確認

你確認過的資料，之後可以被程式記住，讓航海助手慢慢學會你的資料。

# 🚀 船長第一次起航

## 1. 安裝

下載最新版本後解壓縮，開啟執行檔即可。

程式啟動後內建 **「簡易新手指南」**，第一次使用可以直接照著看。

第一次使用建議先進入：

**玩家設定中心**

設定：

* 船隻名稱
* 實際可用負重（LT）
* 個人習慣的交換點縮寫

不用一次把所有設定都研究完。

**先把截圖成功匯入、跑完一次 OCR，就算起航成功。🦭**

---

## 2. 關於自訂縮寫與巴哈島圖分類

助手內建的預設交換點縮寫，是參考巴哈姆特多年前經典文章：

**「從零開始的海上交換 & 造船懶人包」**

裡面的島圖分區方式進行整理。

不過這只是預設值。

如果你不習慣這套縮寫：

* 可以自行修改
* 可以自訂
* 可以取消套用

其他物品縮寫也同樣可以自由修改或關閉。

---

# 📷 3. 遊戲截圖與 A/B 版面技巧

這一區很重要，第一次使用建議看一下。

### 遊戲設定建議

* 畫質：建議 **「中」以上**
* UI 大小：建議調大
* 截圖：盡量保持完整交換畫面

畫面越清楚，越有利於 OCR。

### A / B 版面

以一輪 **15 張交換截圖**為例：

* **A 版：通常是前 14 張**
* **B 版：通常是最後 1 張**

因為最後一張的遊戲版面可能與前面的截圖不同。

### 如果預設版面不準怎麼辦？

不用重新安裝，也不用找作者。

到：

**進階／救援工具 → 裁切／版型校正**

按照畫面重新框一次 A、B 版面並儲存即可。

不同玩家的：

* 螢幕解析度
* Windows 顯示比例
* 遊戲 UI 大小
* 遊戲設定

都可能造成版面位置差異。

所以程式提供這個自救功能，讓玩家可以自己處理。

# 🧠 4. OCR 審查與學習

OCR 完成後會進入：

**人工確認頁**

這不是代表 OCR 失敗。

它的用途是讓你快速檢查：

> 「海豹這次到底有沒有看對？」

### 看對了

直接放行。

### 看錯了

直接手動修改。

### 不確定

點開原始截圖確認。

如果是新的品項或特殊情況，也可以透過確認流程讓程式逐漸累積資料。

---

# 🗺️ 5. 開始規劃路線

OCR 確認完成後：

**路線工作台 → 勾選今天想跑的項目 → 排好路線**

完成後就可以按照路線卡開始跑航程。

而且程式會逐漸累積你的路線經驗。

理想情況下，使用一段時間後：

> 🦭「船長，我好像知道你平常怎麼跑了。」

海豹就可以開始提供路線草稿建議。

（作者目前也還在努力教牠 XD）

# 🛟 6. 遇到問題？不用找作者聊天

如果使用過程中遇到疑難雜症，例如：

* OCR 一直讀錯同一個品項
* 手動修改後下次還是沒學會
* 數量辨識異常
* 某台電腦可以、另一台不行
* A/B 版面位置不正確
* 路線或庫存計算看起來怪怪的

可以使用：

**進階／救援工具 → 資料安全與 AI 自助求救**

產生：

**「求救包 ZIP」**

壓縮包裡有：

**「玩家請先看我」**

按照裡面的說明，把資料交給你自己的 ChatGPT 協助分析即可。

> 💡 這個工具的設計理念就是：
>
> **遇到問題，不一定要找作者。**
>
> 先讓 AI 幫你看看發生了什麼。

特別歡迎不同環境的玩家測試，例如：

* 不同電腦

> 「每次航海交換都要自己整理，好麻煩……」

作者本人：

**不懂程式開發。**

**ChatGPT + Devin + 大量實際測試**

> 「第一次下載就保證所有 OCR 100% 正確。」

而是：

> **OCR → 人工確認 → 記住 → 再測試 → 修正 → 下一個版本**

如果你剛好遇到問題，也歡迎提交 Issue。

**不用會寫程式、不用加入社群，也不用特別跟作者聊天。**

一份測試、一份 OCR 報告，甚至一句：

> 「我的電腦全部正常。」

都能幫助這隻海豹繼續長大。 🦭
