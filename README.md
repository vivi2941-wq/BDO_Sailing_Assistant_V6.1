# 黑色沙漠航海助手 V6.1

一款自動化 OCR 識識黑色沙漠航海交換的輔助工具。

## 功能特點

- 🎯 自動 OCR 識識航海交換資訊
- 📊 自動計算交換比例
- 🧭 路線規劃與管理
- 📦 庫存管理
- 🧠 智能學習與記憶

## 如何使用

1. 下載最新版本的 EXE 檔案
2. 執行程式
3. 截取遊戲畫面
4. 程式自動識識並顯示結果

## 🤝 如何幫助改善 OCR

如果你遇到 OCR 識識錯誤，可以幫忙提交報告：

1. 在 OCR 審查頁面點擊「📊 生成 OCR 報告」按鈕
2. 報告會自動複製到剪貼簿
3. 前往 GitHub Issues，點擊「New Issue」
4. 選擇「OCR 識別報告」模板
5. 貼上報告內容
6. 提交 Issue

你的報告會幫助我們改善 OCR 識識準確度！
