# ⚓ 黑色沙漠航海助手 V6.1 (Black Desert Sailing Assistant)

歡迎來到黑沙航海助手（又名：海豹助手）！這是一款專為《黑色沙漠》大洋大航海與物資交換（Barter）設計的自動化 OCR 桌面輔助工具。

💡 **本專案核心亮點**：本程式是由**完全不懂程式程式碼的作者，100% 透過 AI (ChatGPT & Devin) 協作開發完成**的生產力實驗作品！證明了透過精準的 AI 溝通，非工程師也能打造出功能複雜、完全穩定的圖形桌面應用程式。

---

## 🦭 功能特點

* 🎯 **智慧型 OCR 截圖辨識**：自動導入遊戲物資交換畫面截圖，精準辨識點位與品項數量。支援 **A 一般／B 特殊** 自訂版型校正。
* 📊 **自動計算交換比例**：內建交涉力減免試算與階段物資篩選儀表板，輕鬆規劃今日航線。
* 🧭 **智慧路線規劃與管理**：支援自訂點位縮寫、階段色彩標示，並擁有「滑鼠拖曳換位」排序功能。
* 📦 **嚴格的庫存管理系統**：擁有獨立的測試沙盒與正式庫存模式、對帳稽核線與自動 T5 5階溢出出售提示。
* 🧠 **智能學習與記憶**：內建海豹自適應學習模型，能自動記住船長的排法習慣，並進行航段省時體檢與草稿推薦。

## 🚀 船長起航與實戰指南

### 1. 安裝與新手導航
* 下載並解壓後，開啟執行檔安裝即可啟動可愛的綠色航線介面。
* 程式開啟後內建有**「簡易新手指南」**可供隨時參考。
* 建議最先到「玩家設定中心」設定您的船隻名稱與實際可用負重（LT）。

### 2. 關於自訂縮寫與巴哈島圖分類
* 助手內建的預設交換點縮寫，是參考巴哈姆特多年前經典文章 **'從零開始的海上交換 & 造船懶人包'** 裡的島圖分區進行自訂的。
* **高度自由度**：如果你不習慣這套縮寫，完全可以自行修改、自訂、或直接取消套用縮寫，其他所有的物品縮寫也都支援自由修改或關閉。

### 3. 遊戲截圖與 A/B 版面技巧 (最重要 💡)
* **遊戲設定建議**：在遊戲中截取交換資訊全部圖後匯入助手。遊戲畫質建議設定在 **"中" 以上**、且**介面大小調大**，這會非常利於 AI 讀圖與辨識！
* **網頁圖檔分版規則**：以單輪 15 張截圖為例，通常 **A 版是前 14 張（一般版面）**，而 **B 版是最後 1 張（特殊版面）**。
* **版型自救校正**：因為每位玩家的遊戲 UI 設定與解析度可能不同，雖然助手有做自動換算，但若發現預設版面讀出來不對，可以隨時到「進階／救援工具」裡使用**「裁切／版型校正」**功能，自己手動框一次 AB 版面儲存即可！

### 4. OCR 審查與路線執行
* 截圖跑完 OCR 後會進入「人工確認頁」。如果出現未確認的新品項，點一下原圖看跟 OCR 讀出來的對不對，有錯的直接手動修改，沒問題就點選放行。
* 進入「路線工作台」勾選今天想跑的項目，接著排好路線，就能直接按照精美的路線卡開始快樂跑行程囉！
* **自動路線學習**：程式內建路線學習功能，理想情況下在累積一定的路線經驗後，小海豹助手就能學會你的習慣並自行幫你排好路線（作者正在努力累積經驗中 XD）！

## 🛟 資料安全與 AI 自助求救

如果在操作過程中遇到任何疑難雜症（例如：OCR 同一個品項人工修改了兩三次它居然還沒學會），可以使出專屬自救大絕招：

1. 到「進階／救援工具」裡點選**「資料安全與 AI 自助求救」**。
2. 點擊產生一個**「求救包 (ZIP)」**。
3. 按照壓縮包裡面的 **'玩家請先看我'** 說明文件，將打包好的資料直接貼給你自己的 **ChatGPT** 看，AI 就會立刻化身專業診斷員幫你找出問題！

## 🤝 如何幫助改善 OCR

如果你遇到 OCR 辨識錯誤，非常歡迎幫忙提交數據報告供我們徵集優化：

1. 在 OCR 審查頁面點擊「📊 生成 OCR 報告」按鈕。
2. 報告會自動複製到剪貼簿。
3. 前往本 GitHub 儲存庫的 **Issues**，點擊「New Issue」並貼上報告。

你的報告會幫助我們改善 OCR 識識準確度！
